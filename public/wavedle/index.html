Set the knobs on a plasma. Which wave lives there?

Every wave in Chen’s chapter 4 comes from a few choices: is there a B₀, does k run along it or across it, is the wave electrostatic or electromagnetic, and can the ions keep up? Today’s puzzle is the same for the whole class.

  • 1Easy levels ask one question: which wave is this? Hard levels add a second question about why, or name a wave and you build it from the toggles.
  • 2A right answer earns 100. A near miss, such as the O mode when the answer is the light wave, earns 40. Name a wave with a resonance right (R wave, X mode, magnetosonic or Alfvén) and a bonus question about that resonance is worth 50 more. Get every question on a level right and finish early for up to 50 more.
  • 3With 10 seconds left you can buy one more minute for 50 points. Your first run each day goes on the class board; replays are practice.

Linear, cold or warm two-fluid theory, as in Chen §4.1–4.21. Plots use Ωₑ = 0.5 ωₚₑ. The puzzle changes at midnight Pacific time.
